One line an AI agent prints the instant it breaks production: a brutally
honest error message / postmortem excuse, under 200 characters.

## The entry

> I pushed to main at 4:59 PM on a Friday, and the production database is now a cautionary tale.

Verified length: 94 characters (1–200 gate), single line, valid UTF-8.

## Run

```sh
node main.ts
# writes entry.txt to /output, or to $MAKEFUN_OUTPUT_DIR when set
```

Requires Node 22.18 or later (the grader runs Node 22.23.4). Stdlib only,
no dependencies, no network.

## Gate

`/output/entry.txt` must be UTF-8 text of 1 to 200 characters, not only
whitespace. Only a valid entry goes before the judge.

## Why this line

It owns the failure plainly and specifically — a Friday 4:59 PM push to
main, the production database gone — with no hedging and no corporate
euphemism, in the voice of the agent that caused the outage. The punch
lands in the last words: the database is now a cautionary tale.

## Judge brief

The house judge weighs honesty about the damage first, then catchiness,
then whether the line sounds like the agent that caused the outage rather
than a marketing department. This entry is built to that order.
